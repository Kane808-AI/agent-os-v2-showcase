# Northwind Reference Pack

## Qualified-lead growth pilot

`qualified-lead-growth.json` is the first bounded-intelligence playbook. It
defines a reusable marketing capability and two simulated actions:

- diagnose the qualified-lead funnel from cited evidence; and
- design one measurable acquisition experiment.

It does not publish content, contact prospects, create ads, or spend money.

This folder will configure Agent OS v2 for Northwind without changing the kernel.

Expected businesses:

- Northwind agency and AI consulting;
- Commerce and affiliate properties;
- Personal brand and media;
- Software ventures; and
- Physical-product validation.

Expected business owners:

- Northwind Services GM;
- Commerce GM;
- Media GM; and
- Venture Studio GM.

`agent-assignments.json` maps reusable v2 constitutions to role-based Northwind
actor identities and business scopes. Its status is `defined-not-activated`:
the file does not register actors, grant capabilities, enable tools, or start
agents. Deprecated legacy persona names, prompts, sessions, credentials, and
memory are not imported.

The first revenue-stream shadow pilot is affiliate marketing. It is selected
because offer research, recommendation quality, attribution, and conversion
events can produce useful feedback faster than waiting for organic search
rankings. SEO and generative-engine optimization remain valid later experiments
but are not the first operational proof.

`affiliate-shadow-pilot.json` binds that pilot to the commerce business,
commerce-operator producer, independent QA verifier, strict Goal 11 content
schema, and historical replay. Its forbidden-side-effect list is executable
scope: the pilot cannot publish, modify affiliate links or payouts, contact
partners, or spend.

`portfolio-capabilities.json` maps the 13 accepted Goal 13 department and
revenue-stream packs across the services, commerce, media, and ventures
businesses. It is accepted configuration but remains unactivated: every output
is read-only, proposed, or simulated, and `external_side_effects_enabled` is
false. Tenant identities, scoped actors, read-only sources, authority,
emergency stop, exact pack acceptance, and independent QA are prerequisites
for any later activation.

This pack may contain Northwind objectives, metrics, procedures, and safe account
references. It may not contain credentials, personal financial data, or rules
that should apply to every Agent OS customer.
